# B2.3 Cell specialization — what to watch

Watch **one** main video, then close it and produce the explanation from memory. A second explanation of the same material builds recognition, which is the skill that has been hiding the gaps.

## Main

**Alex Lee Biology — B2.3 Cell specialization**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+B2.3+Cell+specialization>

Alex Lee organizes the course by the current IB topic codes, so begin with the explanation made for B2.3. If the search shows separate SL/HL sections, use the full B2.3 coverage assigned by your teacher.

**Watch for:**

- How a morphogen gradient can make cells with the same genome express different genes.
- What separates self-renewal from differentiation in a stem cell.
- Why increasing cell size lowers surface area-to-volume ratio.
- How every named HL cell links a structural adaptation to one particular function.

**Pause at:** the first comparison of totipotent, pluripotent and multipotent cells. Cover the labels and rebuild the order from greatest to least potency, giving one human example for each level.

## Worth it once, not for revision

Fertilization includes spatial and mechanical events that a still diagram can hide, so an **animation** earns one exception to the one-video rule.

- Search: <https://www.youtube.com/results?search_query=human+fertilization+acrosome+cortical+reaction+animation>

Watch the acrosome reaction, sperm membrane fusion and cortical reaction. Then draw the sequence and label what the acrosome enzymes help the sperm do and how cortical granules help prevent polyspermy.
