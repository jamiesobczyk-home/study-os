# A3.2 Classification and cladistics — what to watch

Watch **one** main video, then close it and draw or explain the ideas from memory. A second explanation of the same material builds recognition, and recognition is the problem you’re trying to replace with recall.

## Main

**Mister Lee Science — A3.2 Classification and cladistics**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+A3.2+Classification+and+cladistics>

Alex Lee organizes his IB Biology material by the current syllabus codes, so begin with the version built for A3.2.

**Watch for:**

- Why a fixed hierarchy of ranks can conflict with the branching pattern produced by evolution.
- What a node means, and how it tells you which taxa share the most recent common ancestor.
- How sequence differences and parsimony are used to construct a cladogram.
- Why molecular-clock dates are estimates rather than exact dates.

**Pause at:** the first cladogram with several named organisms. Cover the explanation, identify the root and every node, circle one complete clade, and name the pair with the most recent common ancestor. Then rotate two branches around a node and check that your answers stay the same.

## Worth it once, not for revision

Rotating branches around a node is a spatial change that’s easier to understand when it moves. An **animation** earns one exception to the one-video rule because it shows why the order of names across the page can change while ancestry stays the same.

- Search: <https://www.youtube.com/results?search_query=cladogram+rotate+branches+around+node+animation>

After watching, draw the same four-taxon cladogram in two different orientations. Label corresponding nodes in both drawings and explain why each version represents the same hypothesis.
