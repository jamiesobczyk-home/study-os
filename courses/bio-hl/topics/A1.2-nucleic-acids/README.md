# A1.2 Nucleic acids

* **Theme:** A — Unity and diversity
* **Level:** Molecules
* **Level of study:** SL and HL
* **Status:** ready

## The one-sentence version

DNA stores instructions in the order of its bases, and its paired strands make those instructions possible to copy and use.

## Why this topic is worth getting right

The difficult part is keeping three things apart: a nucleotide's parts, the covalent bonds along each strand, and the hydrogen bonds between paired bases. Draw them from memory before checking the diagram. If a phosphate ends up between the bases, or both 5′ ends point the same way, you've found something worth fixing.

This structure comes back in DNA replication and protein synthesis. The HL material then asks what experiments and base-composition data told scientists about DNA, so explain each result before you memorize a name.

## In your study guide

Allott, *Biology Study Guide* (2023), **section A1.2, pp. 4–7**. Read it *after* the capture sheet, never before. It's condensed enough to make a fast check of what you left out, and a slow way to meet the topic for the first time.
