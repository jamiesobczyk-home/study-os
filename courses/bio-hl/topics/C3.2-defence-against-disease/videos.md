# C3.2 Defence against disease — what to watch

Watch **one** main video, then close it and produce the immune-response sequence from memory. A second explanation of the same material builds recognition, which is the problem you’re trying to leave behind.

## Main

**Mister Lee Science — C3.2 Defence against disease**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+C3.2+Defence+against+disease>

Alex Lee organizes the course by the current IB topic codes, so start with the version built around C3.2.

**Watch for:**

- Which defenses prevent entry, which respond broadly, and which recognize one antigen.
- What a B-cell must encounter before it becomes activated.
- How one activated B-cell produces both plasma cells and memory cells.
- How individual immune memory connects to vaccination and population-level herd immunity.

**Pause at:** the first diagram of B-cell activation. Cover the labels and say the sequence aloud: specific antigen, matching B-cell, activated helper T-cell, cytokine signaling, clonal expansion, plasma cells, antibodies and memory cells.

## Worth it once, not for revision

Phagocytosis and blood clotting are mechanical sequences, so an **animation** earns an exception to the one-video rule. Movement makes engulfment, vesicle formation and the fibrin mesh easier to place in order.

- Search: <https://www.youtube.com/results?search_query=phagocytosis+and+blood+clotting+animation>

After watching, draw both sequences from memory. For clotting, include platelets, clotting factors, thrombin, fibrinogen, fibrin and trapped erythrocytes. For phagocytosis, include engulfment, a vesicle, lysosomes and digestion.
