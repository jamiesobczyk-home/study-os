# D1.1 DNA replication — what to watch

Watch **one** main video, then close it and draw the process from memory. A second explanation can build recognition again, which is the problem this pack is meant to expose.

## Main

**Alex Lee Biology — D1.1 DNA replication**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+D1.1+DNA+replication>

Alex Lee organizes the course by the current IB topic codes, so start with the explanation made for D1.1.

**Watch for:**

- What remains from the parental DNA in each product molecule.
- Which enzyme separates the strands and which enzyme builds new strands.
- How PCR changes temperature to separate strands, attach primers and extend new DNA.
- Which details belong only to higher level, especially directionality and the leading and lagging strands.

**Pause at:** the first complete replication fork. Copy the fork without labels, add every 5′ and 3′ end, then label the leading strand, lagging strand, primers and Okazaki fragments from the directions alone.

## Worth it once, not for revision

A replication fork is a moving, directional process, so an **animation** earns one exception to the one-video rule. It can show why one new strand is continuous while the other must be assembled in fragments.

- Search: <https://www.youtube.com/results?search_query=DNA+replication+fork+leading+lagging+strand+animation>

Pause while both strands are being synthesized. Trace each template from 3′ to 5′ in the direction its polymerase moves. If either new strand appears to grow 3′ to 5′, redraw the fork.
