# D1.2 Protein synthesis — what you need to be able to do

> Tick a line only after you can do it with the page closed and without prompts.

## Core

- [ ] Explain how RNA polymerase uses one DNA strand as a template to synthesize complementary RNA, including hydrogen bonding, complementary base pairing and uracil in place of thymine.
- [ ] Explain why transcription leaves the DNA template stable and unchanged, allowing the same gene to be transcribed repeatedly.
- [ ] Explain why transcription is required for gene expression and how switching transcription on or off controls which genes are expressed.
- [ ] Explain the roles of mRNA, ribosomes and tRNA in translating an mRNA base sequence into a polypeptide.
- [ ] Use complementary base pairing between an mRNA codon and a tRNA anticodon, keeping the two sequences antiparallel.
- [ ] Describe the genetic code as a triplet code that is degenerate and nearly universal, and explain what each feature means.
- [ ] Use an mRNA codon table to deduce an amino acid sequence, starting at AUG and ending at a stop codon.
- [ ] Explain elongation as the repeated arrival of tRNAs, peptide-bond formation and movement of the ribosome one codon at a time.
- [ ] Explain how a point mutation can change a codon, the amino acid sequence and protein structure, using sickle-cell haemoglobin as an example.

## Higher level

- [ ] State and apply the directionality of transcription and translation: RNA is synthesized 5′ to 3′, and the ribosome moves along mRNA from 5′ to 3′.
- [ ] Explain how a promoter and transcription factors initiate transcription, and distinguish coding DNA from functional non-coding DNA.
- [ ] Explain how eukaryotic pre-mRNA becomes mature mRNA through intron removal, exon splicing, addition of a 5′ cap and addition of a 3′ poly-A tail.
- [ ] Explain how alternative splicing joins different combinations of exons so one gene can produce different polypeptides.
- [ ] Outline translation initiation and track tRNA through the A, P and E sites during elongation.
- [ ] Explain how polypeptides become functional proteins, using preproinsulin processing as an example, and explain why protein breakdown and amino-acid recycling are needed.

## Links to other topics

- **A1.2 Nucleic acids** — nucleotide structure, complementary base pairing and 5′ and 3′ ends supply the chemical language used throughout transcription and translation.
- **B1.2 Proteins** — protein synthesis determines primary structure. B1.2 explains how that amino acid sequence affects folding, shape and function.
- **B2.2 Organelles and compartmentalization** — the nucleus, free ribosomes, rough endoplasmic reticulum and Golgi apparatus give eukaryotic protein production its locations and route.
- **D1.3 Mutations and gene editing** — D1.2 shows how a changed DNA base can reach a protein. D1.3 develops the causes, consequences and modification of those changes.
- **D2.2 Gene expression** — promoters and transcription provide a major control point. D2.2 develops how cells regulate that control.
- **D3.2 Inheritance** — inherited alleles can encode different polypeptides, linking genotype to phenotype through protein structure and function.

## Vocabulary that has to be exact

| Term | What it means | What it’s not |
| --- | --- | --- |
| Transcription | Synthesis of an RNA strand using a DNA strand as a template | Translation of mRNA into a polypeptide |
| Template strand | The DNA strand read by RNA polymerase to build complementary RNA | The DNA strand whose sequence matches the RNA apart from T replacing U |
| Gene expression | Use of information in a gene to produce a functional RNA or polypeptide | Copying the entire genome before cell division |
| Translation | Synthesis of a polypeptide using the codon sequence of mRNA | Changing one nucleotide language into another nucleotide language |
| Codon | A sequence of three bases on mRNA that specifies an amino acid or a stop signal | A three-base sequence on tRNA |
| Anticodon | A three-base sequence on tRNA that pairs antiparallel with an mRNA codon | A codon copied onto tRNA |
| Degenerate code | A genetic code in which more than one codon can specify the same amino acid | A code in which one codon specifies several amino acids |
| Nearly universal code | A code in which the same codons specify the same amino acids in almost all organisms | Evidence that every organism has identical DNA |
| Promoter | A non-coding DNA sequence where transcription factors and RNA polymerase assemble to initiate transcription | The first codon translated by a ribosome |
| Intron | A transcribed sequence removed from eukaryotic pre-mRNA | Any DNA that’s never transcribed |
| Exon | A sequence retained and joined into mature mRNA after splicing | A sequence that must encode an entire protein by itself |
| Alternative splicing | Joining different combinations of exons from one pre-mRNA | A mutation that changes the order of exons in DNA |
| Point mutation | A change affecting one nucleotide pair in DNA | A change that always alters a protein |
| Proteome | The complete set of proteins produced by a cell, tissue or organism at a particular time | The complete set of genes in an organism |
| Proteasome | A protein complex that breaks down damaged or unneeded proteins, enabling their amino acids to be recycled | A ribosome that assembles new polypeptides |
