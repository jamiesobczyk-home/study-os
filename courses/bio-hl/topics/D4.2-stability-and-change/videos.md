# D4.2 Stability and change — what to watch

Watch **one** main video, then close it and reconstruct the causal chains from memory. A second explanation of the same content builds recognition, which is the skill that’s been covering the gaps.

## Main

**Mister Lee Science — D4.2 Stability and change**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+D4.2+Stability+and+change>

Alex Lee organizes the course by the current IB topic codes, so start with the version built for D4.2.

**Watch for:**

- Which four conditions are required for long-term ecosystem stability.
- How Amazon forest loss could weaken its own rainfall and produce a positive feedback.
- Which processes connect nutrient leaching to oxygen depletion during eutrophication.
- Where the video changes from Core content to HL succession.

**Pause at:** the first summary of human impacts. Make four columns headed **pressure**, **ecosystem process**, **measured change** and **possible response**. Fill one row each for deforestation, fertilizer leaching, persistent pollutants and plastics before continuing.

## If that didn’t land

- Channel: <https://www.youtube.com/@khanacademy> — verified

Use this if you can recognize an algal bloom but can’t yet produce the chain from nutrient leaching to increased biochemical oxygen demand and hypoxia.

**Amoeba Sisters — ecological succession**

- Channel: <https://www.youtube.com/@AmoebaSisters> — verified
- Search: <https://www.youtube.com/results?search_query=Amoeba+Sisters+ecological+succession>

Use this for a more visual route through pioneer species, soil development and community replacement. Add the IB-specific trends in primary production, food-web complexity and nutrient cycling from your cards afterward.

## Worth it once, not for revision

Amazon moisture recycling is a spatial process, so an **animation** earns one extra watch. You need to see water moving from forest to atmosphere and back as rainfall, not memorize “trees make rain” as a slogan.

- Search: <https://www.youtube.com/results?search_query=Amazon+rainforest+moisture+recycling+transpiration+animation>

After watching, draw arrows linking forest area, transpiration, atmospheric water vapor, cooling, air flow, rainfall, drought, fire and tree loss. Mark every arrow as an increase or decrease.
