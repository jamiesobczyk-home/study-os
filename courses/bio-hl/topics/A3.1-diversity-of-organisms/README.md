# A3.1 Diversity of organisms

- **Theme:** A — Unity and diversity
- **Level:** Organisms
- **Level of study:** SL and HL
- **Status:** ready

## The one-sentence version

Biologists identify and compare species using traits, reproduction, chromosomes and DNA, but every method has limits that affect what its evidence can show.

## Why this topic is worth getting right

A3.1 is hard because several methods answer different questions: morphology describes shared traits, interbreeding tests reproductive compatibility, karyograms compare chromosomes, and DNA methods compare sequences. If those methods blur together, an answer can contain true biology and still miss the mark. Practice naming the method, the evidence it uses and the limit of its conclusion.

## In your study guide

the capture sheet, never before. It's condensed enough to make a fast check of
