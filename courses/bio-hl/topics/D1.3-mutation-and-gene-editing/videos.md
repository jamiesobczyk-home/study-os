# D1.3 Mutation and gene editing — what to watch

Watch **one** main video, then close it and explain the topic without notes. A second explanation of the same material builds recognition, which is already the problem. The useful test is whether you can produce the causal chain yourself.

## Main

**Mister Lee Science — D1.3 Mutation and gene editing**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+D1.3+Mutation+and+gene+editing>

Alex Lee organizes the course by the current IB topic codes, so begin with the explanation made for D1.3.

**Watch for:**

- How substitutions differ from insertions and deletions at the DNA level.
- Why degeneracy can prevent a substitution from changing an amino acid.
- Why a frameshift changes multiple downstream codons.
- Which content is additional higher level: knockout organisms, CRISPR-Cas9 and conserved sequences.

**Pause at:** the first comparison of an original and mutated sequence. Cover the explanation, identify the mutation type, regroup the sequence into triplets and predict the possible effect on the polypeptide.

## If that didn’t land

**Amoeba Sisters — mutations**

- Channel: <https://www.youtube.com/@AmoebaSisters> — verified

Use this if you need a more visual account of substitutions and frameshifts. Afterward, explain why a one-base deletion often affects more codons than a one-base substitution.

**Khan Academy — mutations and genetic variation**

- Channel: <https://www.youtube.com/@khanacademy> — verified
- Search: <https://www.youtube.com/results?search_query=Khan+Academy+mutations+genetic+variation>

Use this if the link from DNA sequence to protein and phenotype isn’t sticking. Stop once you can trace that link aloud without the video.

## Worth it once, not for revision

CRISPR-Cas9 is a spatial, mechanical process, so an **animation** earns one exception to the one-video rule. Movement makes it easier to see the guide RNA finding complementary DNA, Cas9 cutting and cellular repair changing the sequence.

- Search: <https://www.youtube.com/results?search_query=CRISPR+Cas9+guide+RNA+DNA+repair+animation>

After watching, draw the target DNA, guide RNA and Cas9. Add arrows showing target recognition, cutting and repair. Label which component supplies sequence specificity and which component is the nuclease.
