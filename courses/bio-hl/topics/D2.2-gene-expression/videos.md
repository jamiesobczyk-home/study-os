# D2.2 Gene expression — what to watch

Watch **one** main video, then close it and produce the explanation from memory. A second explanation can make the same ideas feel familiar without making them retrievable, and recognition is the problem you’re trying to fix.

## Main

**Mister Lee Science — D2.2 Gene expression**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+D2.2+Gene+expression>

Alex Lee organizes the course by the current IB topic codes, so start with the explanation built for D2.2.

**Watch for:**

- Where regulation can happen between DNA and a working protein.
- How promoters, enhancers and transcription factors have different jobs.
- Why differentiated cells can have the same genome but different transcriptomes and proteomes.
- How an epigenetic change alters phenotype without altering genotype.

**Pause at:** the first diagram that connects DNA to phenotype. Cover its labels and rebuild the chain as gene, transcription, mRNA, translation, protein function and phenotype. Add one place where transcription can be regulated and one place where translation can be regulated.

## Worth it once, not for revision

Enhancer action is spatial: distant DNA can loop so an enhancer-bound activator interacts with transcription machinery at a promoter. An **animation** earns one exception to the one-video rule because that movement is hard to get from a flat diagram.

- Search: <https://www.youtube.com/results?search_query=enhancer+promoter+DNA+looping+animation>

After watching, draw a gene, promoter and enhancer. Add RNA polymerase and a transcription factor in the correct places, then explain which part is DNA and which part is protein.
