# progress/

His study history lives here, one file per course: `<course>.progress.json`.

These files are tracked on purpose. They hold which cards he has seen, how well
he knew them, and when each is next due — losing them resets every review
interval to day one. Do not hand-edit them, and do not commit a cleared file
over a real one.

The files are created on the first quiz run, so an empty directory here is
normal for a fresh clone.
