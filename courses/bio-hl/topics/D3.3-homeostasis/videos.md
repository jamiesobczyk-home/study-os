# D3.3 Homeostasis — what to watch

Watch **one** main video, then close it and draw the feedback loops from memory. A second explanation of the same material builds recognition, which is the problem you’re trying to get past.

## Main

**Mister Lee Science — D3.3 Homeostasis**

- Channel: <https://www.youtube.com/@misterleescience> — verified
- Search: <https://www.youtube.com/results?search_query=Mister+Lee+Science+D3.3+Homeostasis>

Alex Lee organizes his IB Biology videos by the current syllabus codes, so start with the version built around D3.3.

**Watch for:**

- What detects each change, what coordinates the response and which tissue acts as the effector.
- How insulin and glucagon produce opposite changes in blood glucose concentration.
- Which thermoregulatory responses change heat loss and which ones generate heat.
- At HL, where filtration, selective reabsorption and ADH-controlled water reabsorption occur in the nephron.

**Pause at:** the first complete negative-feedback diagram. Cover its labels and rebuild it twice, once for blood glucose above the set point and once for blood glucose below it. Name the pancreatic cell, hormone and target response in each route.

## Worth it once, not for revision

The nephron is spatial, and aquaporin-containing vesicles move into or out of a cell membrane. An **animation** earns an exception to the one-video rule because movement makes those relationships clearer than a static diagram does.

- Search: <https://www.youtube.com/results?search_query=nephron+loop+of+Henle+ADH+aquaporin+animation>

After watching, draw a nephron and label the glomerulus, Bowman’s capsule, proximal convoluted tubule, loop of Henle and collecting duct. Add one verb beside each structure. If every label says “filters,” the processes still need separating.
